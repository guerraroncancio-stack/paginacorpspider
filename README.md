# Scrims Mixtas · Spider's

Sitio web para gestionar scrims de Free Fire: reserva de cupos, panel de administración, resultados y ranking.

- **Frontend:** HTML + CSS + JavaScript puro (un solo archivo `index.html`).
- **Persistencia:** `localStorage` (los datos viven en el navegador del usuario).
- **OCR opcional:** Tesseract.js (carga desde CDN, no requiere instalación).
- **Sin dependencias de backend.** Se puede alojar en cualquier hosting estático.
